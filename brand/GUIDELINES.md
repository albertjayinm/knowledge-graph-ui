# Knowledge Graph UI: logo guidelines

## 1. The logo
- **Idea:** a four-node pyramid graph whose back link breaks where it passes behind the front link, so the graph reads in 3D. The coloured front node is the node in focus, just as in the app.
- **Versions:** horizontal (primary) · stacked · symbol only · wordmark only · small-size symbol (for 32 px and below).
- **Files** (`final/`):

| Use | File |
|---|---|
| README, app header, website | `horizontal.svg` / `horizontal-dark.svg` |
| Square spaces, title slides | `stacked.svg` / `stacked-dark.svg` |
| Avatars, large icons | `symbol.svg` / `symbol-dark.svg` |
| 32 px and below | `symbol-small.svg` |
| App / PWA icon | `app-icon.svg`, `app-icon-maskable.svg` |
| Favicon & web icon set | `export/` (see `export/head-snippet.html`) |
| One colour, reversed | `export/kg-*-black.svg`, `export/kg-*-white.svg`, `export/kg-*-mono-6c4cf5.svg` |

## 2. Clear space
Keep a clear zone of **1 × the diameter of the front (focus) node** around the logo on all sides. The zone scales with the logo.

## 3. Minimum size
| Version | Screen |
|---|---|
| Horizontal | 160 px wide |
| Stacked | 96 px wide |
| Symbol | 40 px. Below that, use `symbol-small.svg` (down to 16 px) |

## 4. Colour
| Name | HEX | RGB | Role |
|---|---|---|---|
| Ink | `#14152B` | 20 21 43 | Structure on light backgrounds |
| Focus Violet | `#6C4CF5` | 108 76 245 | Focus node, "UI", accents on light (5.2:1 on white) |
| Night | `#0B0C1D` | 11 12 29 | Dark backgrounds, app-icon tile |
| Lavender | `#C9C6FF` | 201 198 255 | Structure on dark backgrounds |
| Signal Cyan | `#22D3EE` | 34 211 238 | Focus node on dark only (1.8:1 on white: never use it on light backgrounds) |

**Approved pairs:** full colour on white · dark version on Night · white on Focus Violet · black or white one-colour.

## 5. Typography
- Wordmark: **Inter Display SemiBold**, outlined as paths, with tracking −1.2 %. "UI" is set in the accent colour.
- UI and documents: Inter, with the system stack as a fallback.
- Licence: SIL Open Font License 1.1 (free for logo use).

## 6. Don'ts
Don't stretch, rotate or reflect the symbol · don't swap the focus-node colour onto the structure · don't use Signal Cyan on light backgrounds · don't add glows, shadows or gradients to the logo itself · don't rearrange the lockup · don't retype the wordmark.

## 7. Source
The artwork is generated by `make_kit.py` (fontTools + Inter). Concept exploration lives in `make_concepts.py` and `concepts/`. Trademark clearance has not been checked; run a search before a public launch.
